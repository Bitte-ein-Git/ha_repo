# 🎬 Pelagica - Home Assistant Addon

Modernes, schnelles und anpassbares Web-Frontend für [Jellyfin](https://jellyfin.org) - direkt in Home Assistant eingebunden!

🎥 **Pelagica Features:**
- Anpassbare Startseite ("Continue Watching", "Recently Added", custom queries)
- Integrierter Video-Player für Filme & TV-Serien
- Music-Player mit Album- & Playlist-Unterstützung
- Schnelle Suche (Cmd+K / Ctrl+K)
- Mehrsprachig
- Responsive Design für Desktop & Mobile
- Custom Themes Support
